Tạo máy ảo Google Cloud VPS Free Tier

Hướng dẫn tạo một máy chủ Ubuntu chạy 24/7 trên Google Cloud mà không tốn đồng nào — cấu hình đúng từng mục để luôn nằm trong hạn mức Always Free.

12 phút đọc Cập nhật 18/11/2026 Google CloudUbuntuFree Tier

01Hiểu Rõ Chính Sách “Always Free” Của Google Cloud #

Google Cloud cho mỗi tài khoản một máy e2-micro miễn phí vĩnh viễn — nhưng chỉ khi máy nằm ở đúng region và dùng đúng loại ổ đĩa. Chỉ cần lệch một lựa chọn, hoá đơn sẽ bắt đầu chạy ngay từ giờ đầu tiên.

1 × e2-micromỗi tháng, toàn tài khoản
30 GBStandard persistent disk
1 GBegress ra Internet / tháng

Chỉ ba region được áp dụng: us-west1, us-central1 và us-east1. Trong ba lựa chọn này, Oregon cho độ trễ tốt nhất khi kết nối từ Việt Nam.

02Các Bước Tạo Máy Ảo Chuẩn Free Tier (Chi Tiết Từng Mục) #

Mở trang tạo máy ảo theo đường dẫn sau trong console:

Truy cập Google Cloud Console Compute Engine VM instances Create Instance

AMachine Configuration Cấu hình máy

Đây là phần quyết định máy có thuộc diện miễn phí hay không. Điền chính xác theo bảng dưới.

BBoot Disk Bước quan trọng nhất

Bước dễ mất tiền nhất — kiểm tra kỹ trước khi bấm Create

Mặc định Google chọn Balanced persistent disk. Loại ổ này không nằm trong Free Tier và bị tính phí theo GB mỗi tháng.

  • Không chọn Ubuntu Pro hay Ubuntu Accelerator — đây là image trả phí bản quyền.
  • Bấm Change trong mục Boot disk để đổi loại ổ đĩa trước khi tạo máy.

Nếu thích dùng dòng lệnh, có thể tạo đúng cấu hình trên chỉ với một lệnh gcloud:

create-vps.sh bash 
# Tạo VPS Free Tier ở Oregongcloud compute instances create vps-free \  --zone=us-west1-b \  --machine-type=e2-micro \  --image-family=ubuntu-2404-lts-amd64 \  --image-project=ubuntu-os-cloud \  --boot-disk-type=pd-standard \  --boot-disk-size=30GB

CBackups Sao lưu

Chọn No backups. Snapshot tự động bị tính phí lưu trữ riêng và không thuộc Free Tier — nếu cần, hãy tự sao lưu dữ liệu quan trọng về máy cá nhân.

DNetworking Mạng

Trong phần Firewall, tích chọn cả hai ô:

  • Allow HTTP traffic — mở cổng 80
  • Allow HTTPS traffic — mở cổng 443

Mẹo: giữ Network Service Tier ở Standard

Ở mục Network interface, đổi tier từ Premium sang Standard để giảm rủi ro phí egress. Nếu định dùng Cloudflare Tunnel, bạn thậm chí không cần mở cổng nào.

ESecurity & Identity Bảo mật

Giữ nguyên mặc định: Service account Compute Engine default, Access scopes Allow default access. Bật Shielded VM không tốn thêm chi phí.

03Hướng Dẫn Kết Nối SSH Vào Máy Ảo Google VPS #

Cách nhanh nhất là bấm nút SSH ngay cạnh tên máy trong danh sách VM instances — trình duyệt sẽ mở một terminal đã đăng nhập sẵn. Để dùng từ máy cá nhân, thêm public key vào mục Metadata → SSH Keys rồi kết nối bằng ssh user@EXTERNAL_IP.

Đọc thêm

Bài Kết nối SSH với máy Linux hướng dẫn chi tiết cách tạo key và cấu hình ~/.ssh/config.

04Tối Ưu Hệ Thống: Cấu Hình Swap RAM (Bắt buộc cho máy VPS có Ram 1GB) #

Với 1 GB RAM, chỉ cần chạy apt upgrade hoặc build một image Docker là máy có thể treo. Tạo file swap 2 GB giúp hệ thống ổn định hơn rất nhiều; phần lệnh chi tiết có trong bài Tạo Swap RAM trên Linux VPS.

05Cài Đặt Docker & Docker Compose (Tùy chọn) #

Nếu bạn triển khai ứng dụng bằng container, cài Docker theo kho chính thức của Docker thay vì gói docker.io của Ubuntu để có bản mới nhất và plugin docker compose.

06Checklist Kiểm Tra Cuối Cùng (Tránh Phát Sinh Tiền) #

Trước khi rời trang, kiểm tra lại năm điểm sau:

  • Region là us-west1, us-central1 hoặc us-east1.
  • Machine type là e2-micro và chỉ có một máy như vậy trong tài khoản.
  • Boot disk là Standard persistent disk, dung lượng ≤ 30 GB.
  • Không bật Backups / Snapshot schedule.
  • Đã tạo Budget alert ở mức 1 USD trong Billing để được báo sớm.
