# raymond

Web cá nhân làm bằng [Astro](https://docs.astro.build), deploy lên GitHub Pages:
https://www.raymondtruong.io.vn/

## Lệnh thường dùng

| Lệnh              | Tác dụng                                          |
| :---------------- | :------------------------------------------------ |
| `npm install`     | Cài dependencies                                  |
| `npm run dev`     | Chạy local tại `http://localhost:4321/`           |
| `npm run build`   | Build ra thư mục `dist/`                          |
| `npm run preview` | Xem thử bản build                                 |

Push lên nhánh `main` sẽ tự động deploy qua GitHub Actions.
